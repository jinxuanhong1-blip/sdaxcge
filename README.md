# SCLC open-data analyses

The current result set evaluates pretreatment `TACSTD2`/`CLDN4` expression
against clinical outcome in publicly accessible SCLC immune-checkpoint
inhibitor cohorts.

- Results: [`results/w200/SCLC_open/`](results/w200/SCLC_open/)
- Reproducible analysis: [`scripts/analyze_sclc_open.py`](scripts/analyze_sclc_open.py)

Controlled and request-only datasets are audited but are not used.
