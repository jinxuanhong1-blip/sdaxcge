# Leftover public lung spatial (TACSTD2 / CLDN4)

Additive analysis of 2023–2026 GEO/ArrayExpress lung Visium, GeoMx, and CosMx series that still have TACSTD2 or CLDN4 after a real gene check.

User B6 is taken as given. GSE221322, 10x FFPE Visium (PR #126), E-MTAB-13530 (PR #134), and CosMx PR #164 are not repeated.

- Methods: `methods/leftover_spatial/playbook.md`
- Results and extra figures: `results/leftover_spatial/`
