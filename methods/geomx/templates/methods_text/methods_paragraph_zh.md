## 组织与 GeoMx WTA

对 `[n]` 例 `[NSCLC 腺癌 / 鳞癌 / 混合]` 患者的福尔马林固定石蜡包埋 `[手术切除 / 活检 / 组织芯片]` 切片，使用 GeoMx Digital Spatial Profiler 与 Human Whole Transcriptome Atlas（约 18,000 个蛋白编码靶标）进行空间转录组检测。形态学标记为广谱细胞角蛋白（肿瘤）、CD45（白细胞）、CD68（巨噬细胞）及 SYTO 13（细胞核）。每个肿瘤放置 `[k]` 个感兴趣区域（ROI，范围 `[–]`），每个 ROI 再分割为上述三个分区，质控前共 `[N_AOI_in]` 个照明区域（AOI）。公开的数字计数转换（DCC）文件来自 GEO `[GSE271689 / GSE292098]`，未使用任何受限访问计数。

## 质控

使用 GeomxTools，按分区分别设置细胞核与面积下限（肿瘤：`[100]` 个核 / `[5000]` µm²；CD45：`[50]` / `[2000]`；CD68：`[20]` / `[1000]`），并要求原始 reads ≥ `[1000]`、修剪/拼接/比对比例各 ≥ `[80]`%、测序饱和度 ≥ `[50]`%、阴性探针几何均值 ≥ `[10]`、空白对照孔计数 ≤ `[1000]`。第 *i* 个 AOI 的定量下限为 `LOQ_i = max(2, geomean(NegProbe_i) × geoSD(NegProbe_i)²)`。高于 LOQ 的靶标检出率 < `[1]`% 的 AOI 被剔除。基因保留标准为：在**至少一个分区**内 ≥ `[5]`% 的 AOI 高于 LOQ（并集，用于分区内分析）；跨分区对比限制在三个分区基因表的交集。质控后保留 `[N_AOI_out]` 个 AOI、`[N_gene]` 个基因（肿瘤 `[n_tumor]`、CD45 `[n_CD45]`、CD68 `[n_CD68]`）。各步骤按分区拆分的 AOI 剔除计数见补充表 `[ ]`。

## 归一化与批次

在查看差异表达结果**之前**指定 `[TMM / Q3 / 分位数]` 为主归一化方法。`[Q3 与分位数]` 作为敏感性分析，并通过相对对数表达图以及按分区、玻片、AOI 面积、检出率着色的主成分进行比较（补充图 `[ ]`）。跨分区对比使用合并归一化后的计数；分区内分析`[使用同一矩阵 / 在分区内重新归一化]`。玻片`[作为随机效应纳入模型 / 经检查与队列无完全混杂]`。批次校正矩阵（RUV4 / `removeBatchEffect`）仅用于可视化，不作为推断输入。

## 差异表达与混合模型

独立实验单元为患者。全基因组差异表达采用 limma-voom，并以患者为 block 进行 `duplicateCorrelation`（共识相关超过 0.5 时跑两轮）。共识相关为 `[ρ]`。*P* 值在**每个对比内部**做 Benjamini–Hochberg 校正。同一组织内共存的分区（肿瘤 vs CD45 vs CD68）另用线性混合模型拟合，包含患者随机截距与随机分区斜率，自由度采用 Kenward–Roger（或 Satterthwaite）。事先指定的敏感性分析为患者 × 分区的 pseudobulk；若与 voom 拟合方向不一致，以 pseudobulk 为准。未使用把 AOI 当作独立观测的 *t* 检验。

## TACSTD2 与 CLDN4

`TACSTD2` 与 `CLDN4` 为事先指定的靶点。对每个基因报告：(i) 各分区高于 LOQ 的 AOI 比例；(ii) 混合模型给出的肿瘤–免疫 log2 差值及其 95% 置信区间，以及差值为正的患者比例；(iii) 患者内 ICC，以及使患者层面可靠性 ≥ 0.8 所需的 ROI 数。免疫 AOI 中的信号与上皮渗漏指数（`EPCAM`、`KRT8`、`KRT18`、`KRT19`、`CDH1`）对照，报告相关系数以及限制在最低渗漏三分位后的估计。`[以 PanCK+ AOI 设定 is_pure_tumor 的 SpatialDecon / 同一蜡块的 IHC]` 作为正交对照。肿瘤相对免疫的 log fold change 解释为分区特异性的下界。

## 患者层面评分与总生存

AOI 水平表达按 `[BLUP 收缩 / 中位数 / 按细胞核加权均值]` 聚合为每位患者每个分区一个数值。事先指定并分别检验四个暴露：肿瘤分区表达、免疫分区表达、肿瘤–免疫差值（特异性）、患者内跨 ROI 标准差（异质性）。患者均值的可靠性与每个风险比一并报告。主生存模型为患者层面 Cox 模型，暴露按标准差标准化，校正 `[年龄、性别、分期、组织学]`，并按 `[队列]` 分层。用标准化 Schoenfeld 残差检查比例风险，用 3 节点限制性立方样条检查函数形式。带患者聚类（稳健三明治方差）或共享脆弱项的 AOI 层面 Cox 模型仅作敏感性分析：它们复制事件，并不增加关于该事件的信息。切点`[未使用 / 为训练集中位数或三分位，在 Yale 队列锁定后原封不动用于 UQ 与雅典队列]`。主模型纳入 `[n]` 例患者、`[e]` 例死亡（每变量 `[e/p]` 个事件）。若进行全基因组生存筛查，定位为假设生成。
