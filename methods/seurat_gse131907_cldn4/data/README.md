# Locked gene families

`families.json` is the concordant-4 / A8 lock used across this repo:

- **IFN** = Hallmark interferon-alpha ∪ interferon-gamma
- **MHC_I_APM** = custom MHC-I / antigen-processing panel
- **TJ_no_CLDN4** = KEGG tight junction ∪ GOBP tight-junction organization, **CLDN4 held out**
- **chemokine** = compact chemokine / receptor panel

CLDN4-only. No TACSTD2∩CLDN4 dual-high list lives here.
