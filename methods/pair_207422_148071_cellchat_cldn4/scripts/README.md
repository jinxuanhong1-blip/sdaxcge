# scripts

`analyze.py` reads the given CellChat / TISCH / DRMref tables in `../data`, writes combo rho + consensus LR tables to `../results`, and extra figures to `../figures` (also copied into `../results`).

```bash
python3 methods/pair_207422_148071_cellchat_cldn4/scripts/analyze.py
```

Does not download GEO matrices. Does not run CellChat R.
