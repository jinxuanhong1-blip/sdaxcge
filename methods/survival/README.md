# methods/survival

Bilingual playbook for time-to-event analysis of ICI biomarkers, written for
TACSTD2 (TROP2) and CLDN4. Demo only on open GEO series that actually deposit
PFS (GSE135222, GSE190265). No fabricated statistics.

- [`playbook.md`](playbook.md) — methods (English + 中文)
- [`templates/python/`](templates/python/) — lifelines / scikit-survival
- [`templates/R/`](templates/R/) — survival / survminer / timeROC / cmprsk
- [`demo/`](demo/) — fetch + analysis on the two GEO PFS cohorts
