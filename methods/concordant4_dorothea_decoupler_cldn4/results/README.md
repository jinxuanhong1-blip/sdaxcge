`tf_focus.tsv` is the pre-specified TF table (all four methods).
`direction_vs_kd.tsv` labels each coefficient against the IFN-up-after-CLDN4-loss expectation.
`gene_programs.tsv` is the non-TF comparison on the same matrix, including NLRC5 as a transcript.
`stat1_target_split.tsv` separates Hallmark IFN targets from the rest of the STAT1 regulon.
`sweep_panel.tsv` is one row per network, method, cutoff, and scope.
`sweep_counts.tsv` counts how many of those rows match both arms.
`sweep_long.tsv` is the feature-level table behind the panel.
