# opus_depmap

Public DepMap / CCLE analysis of **TACSTD2** and **CLDN4** in lung cancer cell lines.

- Data: DepMap Public 24Q4, figshare DOI `10.6084/m9.figshare.27993248` (open files only).
- Scripts: `scripts/opus_depmap/`
- Tables and figures: `results/opus_depmap/`
- Narrative: `WRITEUP.md` (Chinese + English)

Nothing in this slice writes outside `notes/opus_depmap/`, `scripts/opus_depmap/` and `results/opus_depmap/` (plus a git-ignored local data cache).
