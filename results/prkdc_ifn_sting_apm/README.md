Public GEO screen of DNA-PKcs (PRKDC) inhibitor and knockdown expression profiles in epithelial and cancer cells. Scores are IFN, a STING transcriptional readout, and antigen-presentation machinery, then a study-level random-effects meta-analysis.

See `WRITEUP.md`. Matrices are downloaded from GEO and are not stored in this repository.

```bash
bash results/prkdc_ifn_sting_apm/scripts/download.sh
python3 results/prkdc_ifn_sting_apm/scripts/score_meta.py
```
