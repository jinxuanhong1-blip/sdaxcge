**图 1l | 肿瘤细胞 TACSTD2 与 Hallmark 顶端连接评分同向变化；TACSTD2 与该评分均不随 T/NK 比例变化。**

恶性细胞伪批量表达和 T/NK 比例来自已锁定的 concordant-4 人 NSCLC 队列。森林图中的每个点是一个队列的 Spearman 系数，横线是 Fisher *z* 95% 区间，菱形是这些系数的 DerSimonian–Laird 随机效应合并值，再变换回 ρ。图上的数字是保留两位小数的 ρ。三条关系分别估计：TACSTD2–连接与 TACSTD2–T/NK 并不蕴含连接–T/NK。

**a**，肿瘤细胞 TACSTD2 对 Hallmark 顶端连接评分（log2(TMM-CPM+1) 的均值，194 个基因）。GSE123902，13 名供体，ρ = 0.48（95% CI −0.09 至 0.82），P = 0.094。GSE131907，21 个样本，ρ = 0.27（−0.19 至 0.63），P = 0.24。GSE205335，21 例患者，ρ = 0.61（0.25 至 0.83），P = 0.003。GSE189357，9 例患者，ρ = 0.12（−0.59 至 0.72），P = 0.77。合并 ρ = 0.43（0.18 至 0.62），P = 9.8 × 10⁻⁴，n = 64 个单位，I² = 0%。未四舍五入的合并 ρ = 0.428。

**b**，同一单位中肿瘤细胞 TACSTD2 对 T/NK 比例。GSE123902，ρ = 0.03（−0.53 至 0.57），P = 0.91。GSE131907，ρ = 0.26（−0.20 至 0.62），P = 0.26。GSE205335，ρ = 0.21（−0.25 至 0.59），P = 0.37。GSE189357，ρ = −0.12（−0.72 至 0.59），P = 0.77。合并 ρ = 0.15（−0.12 至 0.40），P = 0.26，n = 64，I² = 0%。未四舍五入的合并 ρ = 0.155。估计值弱且为正，不能作为 TACSTD2 高的肿瘤淋巴细胞稀少的证据。

**c**，同一连接评分对 T/NK 比例。GSE123902，ρ = −0.07（−0.60 至 0.50），P = 0.83。GSE131907，ρ = −0.17（−0.56 至 0.29），P = 0.47。GSE205335，ρ = 0.44（0.01 至 0.73），P = 0.047。GSE189357，ρ = 0.42（−0.34 至 0.85），P = 0.26。合并 ρ = 0.15（−0.20 至 0.46），P = 0.41，n = 64，I² = 35%。未四舍五入的合并 ρ = 0.146。各队列符号不一致，合并结果与无关联相容。**a** 不能代替 **c**。

分析单位是供体（GSE123902；Laughney 2020；标记定义的恶性细胞；已排除正常肺）、样本（GSE131907；Kim 2020；作者定义的恶性细胞；肿瘤来源且恶性细胞至少 20 个的样本）或患者（GSE205335，作者定义的恶性细胞；GSE189357，Zhu/Wang，标记定义的恶性细胞）。n 是单位数，不是细胞数。锁定的 concordant-4 表有 65 个单位。P4001（GSE205335）没有恶性细胞计数列，故省略；各面板使用同一批 64 个单位。纳入不取决于相关的方向或 P 值。

连接评分是 MSigDB Hallmark 顶端连接（HALLMARK_APICAL_JUNCTION，冻结集 200 个基因）。TACSTD2 不是成员。表达过滤（≥3 个单位中 count ≥ 10）后缺 6 个基因：ACTC1、ACTN3、CD209、DMP1、DSC1、NRAP。评分是其余 194 个基因 log2(TMM-CPM+1) 的不加权均值，各队列使用同一基因表。CLDN4 在这 194 个基因之中。

既往恶性细胞 CLDN4 阳性比例对 T/NK（图 5 / PR #780；n = 65；合并 ρ = −0.53）属于 Part 2。本图不重绘该结果，也不把它当作 TROP2 证据。

扩展数据散点：每个纳入单位一个点，队列 Spearman ρ、P 和 n 标在面板上方。同一行共用坐标范围。扩展数据敏感性：去掉 CLDN4（193 个基因）后，TACSTD2–连接的合并 ρ = 0.42（0.17 至 0.61），P = 0.001，I² = 0%；连接–T/NK 的合并 ρ = 0.18（−0.20 至 0.50），P = 0.36，I² = 45%。KEGG 紧密连接均值（同一过滤后 154 个基因；TACSTD2 被剔除，但它本来就不是成员）给出 TACSTD2–连接 ρ = 0.42（0.16 至 0.63），P = 0.003，I² = 13%；连接–T/NK ρ = 0.11（−0.38 至 0.56），P = 0.66，I² = 70%。KEGG–T/NK 的队列符号不一致。TACSTD2 对 T/NK 不使用连接评分，因此上述敏感性不改变 **b**。

P 值为双侧，三条预先指定的关系之间不做校正。合并 P 值是 Fisher *z* 尺度上的正态检验。Hartung–Knapp *t* 的 P 值（自由度 3）在 **a**、**b**、**c** 中分别为 0.038、0.13 和 0.45，记在 `KEY_STATS.json`，不画入图中。全精度系数见 `source_data/effects.tsv`。
