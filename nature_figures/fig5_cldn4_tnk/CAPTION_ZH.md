**图 5 | 在四个方向一致的队列中，恶性细胞 CLDN4 阳性百分比与 T/NK 比例呈负相关。**

**a**，65 个肿瘤单位中，恶性细胞 CLDN4⁺ 百分比与 T/NK 比例。GSE123902：供者，标志物定义的恶性细胞，n = 13（Laughney 2020；已去除正常样本）。GSE131907：样本，作者定义的恶性细胞，取自荷瘤部位，n = 21（Kim 2020）。GSE205335：患者，作者定义的恶性细胞，晚期免疫检查点抑制治疗，含各亚型，n = 22。GSE189357：患者，标志物定义的恶性细胞，n = 9（Zhu/Wang，AIS–IAC）。灰色线是穿过这 65 个点的普通最小二乘参照线。图中标注的是四个队列 Spearman 系数经 Fisher *z* 变换后的 DerSimonian–Laird 合并值：ρ = −0.53，P = 1.6 × 10⁻⁵，n = 65 个单位，I² = 0%。把 65 个点叠在一起做一次 Spearman 相关，系数为 −0.55。图中标注的 ρ 是队列水平的合并值。

**b**，队列内 CLDN4 四分位 Q1（低；n = 19）与 Q4（高；n = 16）的 T/NK 比例。四分位在各队列内按秩划分后再合并。箱线为中位数与四分位距，须线为 1.5 倍四分位距，每个单位均画出。中位数为 0.43 与 0.12（Δ 中位数 = −0.31）。秩双列相关 r = −0.72。双侧 P = 2.9 × 10⁻⁴。颜色与 **a** 相同。GSE189357 贡献 3 个 Q1 与 2 个 Q4 单位；该队列未报告队列内 Q4 对 Q1 的检验，图中也不显示。

**c**，各队列中 CLDN4 阳性百分比与 T/NK 比例的 Spearman ρ，以及合并估计。点的面积随单位数变化。`tnk_singles.tsv` 不含各队列的置信区间。菱形为合并 ρ（−0.53）及其报告的 95% CI（−0.70 至 −0.31）。I² = 0%。各队列：GSE123902，ρ = −0.66，P = 0.014，n = 13；GSE131907，ρ = −0.52，P = 0.015，n = 21；GSE205335，ρ = −0.44，P = 0.043，n = 22；GSE189357，ρ = −0.60，P = 0.088，n = 9。
