# W200-A4 · TISMO Cldn4 after ICB (same 64 groups as Tacstd2)

Downloads the official TISMO in-vivo ICB gene-module tables for `Cldn4`
and `Tacstd2`, then scores Cldn4 on the **exact 64 comparison groups**
that recover the Tacstd2 49/64 claim.

```bash
python3 scripts/w200/A4_Cldn4/download.py
python3 scripts/w200/A4_Cldn4/analyze.py
```

Outputs: `results/w200/A4_Cldn4/`.
