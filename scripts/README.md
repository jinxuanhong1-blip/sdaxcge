# Scripts

| File | Role |
|---|---|
| `tismo_client.py` | Public TISMO API (no login) |
| `download_tismo.py` | In-vivo ICB + in-vitro IFNg tables for Tacstd2 / Cldn4 / TJ genes |
| `analyze_tismo.py` | 64-slice pairing, stats, waterfalls, paired-mean plots |
| `analyze_gemm.py` | GSE182228 (KL), GSE114601 (KP), GSE157880 (HKP1), GSE169194 (KPM) |
| `download_gemm.py` | Optional standalone GEO fetch (also done inside `analyze_gemm.py`) |
